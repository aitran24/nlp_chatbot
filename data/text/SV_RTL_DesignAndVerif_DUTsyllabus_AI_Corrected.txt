9. Course description:   

=== TRANG 2 ===
2 
          This course introduces students to the core principles of digital hardware design 
using SystemVerilog, covering everything from basic syntax and simulation to 
synthesizable RTL modeling. Through hands -on coding and simulation exercises, 
learners will gain the skills to describe, verify, and implement digital logic systems. The 
course also provides insight into industry -standard design flows and prepares students 
for real -world IC design challenges.  
 
10. Course learning outcomes (CLOs):   
At the end of this course, students should be able to:  
No (CLOs)  
1.  Explain the purpose of HDLs/VDLs in the IC development process  
2.  Describe the major steps in a typical ASIC/SOC design and verification flow  
3.  Understand SystemVerilog syntax, data types, and operators  
4.  Write simple SystemVerilog modules with ports and parameters  
5.  Use procedural blocks and control flow statements for simulation modeling  
6.  Understand the fundamentals of event -driven simulation  
7.  Write tasks and functions, use system tasks and functions  
8.  Explain the role of SystemVerilog  simulation models within an ASIC library 
context.   
9.  Model combinational and sequential standard cells using SystemVerilog 
constructs.  
10.  Learn RTL design principles and styles  
11.  Able to write RTL models for combinational and sequential circuits  
12.  Compile and run SystemVerilog simulations  
13.  Able to write SystemVerilog  models for common digital circuits such as ALUs 
and finite state machines (FSMs)  
14.  Able to interpret and analyze simulation results presented in both text logs and 
waveform displays  
15.  Able to identify and resolve design bugs to ensure successful simulation  
16.  Implement basic power -aware design techniques  and understand fundamental 
Design for Test (DFT) concepts
